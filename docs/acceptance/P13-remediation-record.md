# P13 安全整改与验收记录

整改日期：2026-08-05

## 整改内容

1. 保留现有 SQLite 健康数据、风险评分、个人基线、设备接入、家庭授权和报告逻辑，新增数据库用户凭据字段及唯一用户名索引。
2. 个人账号和系统管理员的首次密码均从环境变量读取，使用 PBKDF2-SHA256、210000 次迭代和独立随机盐保存。
3. 新增 HS256 JWT，包含用户、角色、令牌版本、签发时间和过期时间；服务端校验签名、有效期、账号状态、角色和令牌版本。
4. 除健康检查和登录外，全部 API 必须认证；个人用户越权访问管理接口返回 403，未登录或令牌无效返回 401。
5. 数据查询和写入范围由令牌中的主体用户确定，不再接受客户端传入用户编号；风险、行动计划、报告、家庭成员、设备和生活记录均按用户过滤。
6. 前端登录改为“角色、用户名、密码”，不再接受任意访问码；启动时通过 `/api/v1/auth/me` 恢复会话，401 清理会话，403 保留登录并显示错误。
7. 当前用户权限使用中文名称展示，个人用户不再请求管理员审计接口。
8. 移动端顶部导航改为三列两行，六个入口均完整显示，无横向滚动。
