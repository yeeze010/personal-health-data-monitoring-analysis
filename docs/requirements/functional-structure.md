# 功能结构清单

## 1. 一级模块

| 一级模块 | 二级能力 | MVP 状态 | 说明 |
|---|---|---|---|
| 用户与档案 | 登录、个人档案、健康画像 | 已实现骨架 | 当前代码已提供单用户演示档案与概要信息接口 |
| 健康数据采集 | 指标录入、历史记录、批量导入 | 部分实现 | 已支持手工录入与记录查询，批量导入保留在接口规划 |
| 趋势分析 | 指标趋势、区间对比、异常识别 | 已实现骨架 | 已提供趋势查询与前端图表渲染 |
| 风险预警 | 风险规则、事件触发、人工处置 | 已实现骨架 | 已支持阈值判定、事件生成、处理闭环 |
| 报告中心 | 周报、月报、报告列表、导出 | 部分实现 | 已支持周报/月报生成，导出能力待扩展 |
| 管理后台 | 指标字典、规则配置、审计日志 | 已实现骨架 | 已有只读后台查询接口 |
| 文件与附件 | 上传、归档、下载、权限控制 | 规划中 | 现阶段仅有文档规划，未落代码 |
| 家庭协同 | 家属授权、查看受托数据、隐私审计 | 规划中 | 现阶段保留在需求与 API 规划 |
| 设备接入 | 厂商绑定、同步任务、同步日志 | 规划中 | 现阶段保留在需求与 API 规划 |

## 2. 角色视角功能矩阵

| 角色 | 核心动作 | 关注结果 |
|---|---|---|
| 个人用户 | 录入体征、查看趋势、生成报告、处理提醒 | 了解健康状态并形成留痕 |
| 家属/照护者 | 查看授权范围内数据、关注高风险提醒 | 快速介入异常情况 |
| 医护/健康顾问 | 查看报告、复核风险、给出处置建议 | 提升干预效率 |
| 平台运营 | 管理指标、维护规则、审计操作记录 | 保证平台稳定与合规 |

## 3. 业务闭环映射

| 环节 | 输入 | 系统动作 | 输出 |
|---|---|---|---|
| 数据采集 | 手工录入/设备同步 | 落库、格式校验、审计记录 | 健康记录 |
| 规则计算 | 健康记录 | 阈值匹配、生成风险事件 | 风险预警 |
| 人工处置 | 风险事件 | 记录处理意见、更新状态 | 已处理事件 |
| 报表生成 | 周期范围、用户数据 | 汇总均值/极值/风险数 | 周报/月报 |
| 运营监管 | 规则、日志、统计数据 | 审核变更、追踪操作 | 审计与运营视图 |

## 4. 本轮验收补齐项

- 为产品文档补足页面清单，明确前台与后台的页面边界。
- 为报表与告警定义指标口径，减少后续实现偏差。
- 将 GitHub Issue、PR、CI 规范从文档落为仓库真实文件。
