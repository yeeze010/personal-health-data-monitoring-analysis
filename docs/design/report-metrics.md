# 报表指标与口径

## 1. 首页核心 KPI

| 指标 | 口径定义 | 数据来源 | 更新频率 |
|---|---|---|---|
| 健康分 | 根据最近一批指标是否落在正常区间计算的综合分值 | `/api/v1/summary` | 每次刷新实时计算 |
| 总记录数 | `health_records` 总条数 | `/api/v1/summary` | 实时 |
| 未处理风险数 | `risk_events` 中 `status=open` 数量 | `/api/v1/summary` | 实时 |
| 报告总数 | `health_reports` 总条数 | `/api/v1/summary` | 实时 |

## 2. 趋势分析指标

| 指标 | 展示方式 | 业务解释 |
|---|---|---|
| 收缩压/舒张压 | 折线图 + 正常区间 | 识别高血压风险趋势 |
| 血糖 | 折线图 + 正常区间 | 识别高血糖波动与异常点 |
| 心率 | 折线图 + 正常区间 | 识别静息心率异常 |
| 体重 | 折线图 | 观察周期变化 |
| 睡眠时长 | 折线图 + 阈值参考 | 识别睡眠不足问题 |
| 血氧 | 折线图 + 阈值参考 | 识别低血氧风险 |

## 3. 风险管理指标

| 指标 | 口径定义 | 用途 |
|---|---|---|
| 风险触发次数 | 周期内新生成风险事件数量 | 衡量异常频率 |
| 高风险占比 | `level=high` 风险数 / 全部风险数 | 判断预警严重度 |
| 处理闭环率 | 已处理风险数 / 风险总数 | 衡量处置效率 |
| 平均处理时长 | 风险创建到处理完成的平均时长 | 衡量响应效率 |

## 4. 报告输出指标

| 报表 | 核心字段 | 当前实现 |
|---|---|---|
| 周报 | 周期、记录总数、未处理风险数、核心指标均值 | 已实现 |
| 月报 | 周期、记录总数、未处理风险数、核心指标均值 | 已实现 |
| 专项风险报告 | 指标异常次数、风险处置建议、附件 | 规划中 |
| 家庭共享报告 | 授权范围、健康摘要、关注项 | 规划中 |

## 5. 报表验收标准

- 生成后的摘要必须包含统计周期、记录条数和风险数量。
- 同一周期重复生成报表时，允许产生多版本，但需保留创建时间。
- 周报与月报的周期范围计算必须稳定，不受前端时区格式影响。
