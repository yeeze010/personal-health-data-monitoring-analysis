# 页面清单

## 1. 前台页面

| 页面 | 路由 | 用户角色 | 核心内容 | 当前状态 |
|---|---|---|---|---|
| 健康总览页 | `/` | 个人用户 | 档案摘要、健康分、最新指标、风险、报告 | 已实现 |
| 指标录入区 | `/` 同页模块 | 个人用户 | 指标选择、数值录入、测量时间、备注 | 已实现 |
| 趋势分析区 | `/` 同页模块 | 个人用户 | 指标切换、趋势图、正常区间参考 | 已实现 |
| 风险提醒区 | `/` 同页模块 | 个人用户 | 风险事件列表、处理按钮、处理说明 | 已实现 |
| 报告中心区 | `/` 同页模块 | 个人用户 | 周报/月报生成、报告列表 | 已实现 |
| 运营后台区 | `/` 同页模块 | 平台运营 | 风险规则只读表、审计日志 | 已实现 |

## 2. 后续拆分页面建议

| 页面 | 目标路由 | 触发条件 | 价值 |
|---|---|---|---|
| 登录与身份认证 | `/login` | 引入多用户与 JWT | 形成真正的鉴权闭环 |
| 个人健康档案页 | `/profile` | 支持档案编辑 | 将演示档案变为真实数据入口 |
| 健康记录列表页 | `/records` | 数据量增大 | 支持分页、筛选、导出 |
| 家庭授权页 | `/family` | 启用家属协同 | 管理查看权限和授权关系 |
| 设备接入页 | `/devices` | 接入穿戴设备 | 展示绑定状态与同步日志 |
| 文件资料页 | `/files` | 开启报告附件能力 | 管理 PDF、图片与体检单 |
| 风险规则配置页 | `/admin/rules` | 后台支持增删改 | 提升规则运营效率 |
| 审计与报表页 | `/admin/audit` | 运营规模扩大 | 支持查询、过滤和下载 |

## 3. 页面验收要点

| 页面/模块 | 验收点 |
|---|---|
| 健康总览页 | 首屏 3 秒内渲染完成，关键 KPI 显示正确 |
| 指标录入区 | 表单校验生效，提交后摘要、趋势、风险联动刷新 |
| 趋势分析区 | 指标切换可用，图表显示正常区间与数值标签 |
| 风险提醒区 | 未处理事件可关闭，关闭后状态变化可见 |
| 报告中心区 | 周报、月报生成成功并进入列表 |
| 运营后台区 | 规则和审计日志可加载且字段完整 |
