工程规范

  • Git 分支建议：`main`、`develop`、`feature/*`、`release/*`、`hotfix/*`。
  • PR 必须附带需求点、测试证据、截图或接口响应。
  • CI 需执行 Python 单元测试、前端语法检查与冒烟验证。
  • 部署默认采用 Docker + Nginx，后续可升级 PostgreSQL、Redis 与对象存储。
